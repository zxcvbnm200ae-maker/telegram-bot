# Noor Telegram Project Builder — Render

بوت تيليجرام متخصص في بناء المشاريع البرمجية. يستقبل وصف المشروع أو صورة مخطط مع شرح،
ويطلب من نموذج OpenAI إنشاء ملفات المشروع، ثم يجري فحوصات متاحة ويحاول إصلاح الفشل،
وبعدها يرسل ملف ZIP عند اجتياز الفحوصات.

## النشر على GitHub و Render

1. فك ضغط هذا المجلد على جهازك.
2. أنشئ مستودع GitHub جديداً وارفع **محتويات مجلد `noor_telegram_builder`** إلى جذر المستودع
   (يجب أن يظهر `render.yaml` و`bot.py` في الصفحة الرئيسية للمستودع).
3. افتح Render وسجّل الدخول، ثم اختر **New + → Blueprint**.
4. اربط حساب GitHub واختر المستودع الذي رفعت إليه الملفات.
5. سيقرأ Render ملف `render.yaml` وينشئ Background Worker. هذا النوع مناسب لبوت Telegram
   الذي يستخدم polling ولا يحتاج إلى رابط ويب أو Web Service.
6. قبل تشغيل الخدمة، افتح إعدادات الخدمة في Render → Environment وأضف القيم التالية:
   - `TELEGRAM_BOT_TOKEN`: رمز البوت من BotFather.
   - `OPENAI_API_KEY`: مفتاح OpenAI API من منصة OpenAI.
   - `NOOR_ALLOWED_USER_IDS`: رقم Telegram الرقمي لحسابك. يمكنك معرفته عبر بوت موثوق مثل
     `@userinfobot`. للأكثر من مستخدم، افصل الأرقام بفواصل.
   - `NOOR_MODEL`: اترك `gpt-4.1-mini` أو غيّره إلى نموذج متاح لحساب API لديك.
7. احفظ التغييرات ثم راقب **Logs**. عند ظهور رسالة بدء البوت، افتح تيليجرام وأرسل `/start`.

## المتغيرات السرية

لا تضع رمز Telegram أو مفتاح OpenAI داخل ملفات Python أو GitHub. أدخلهما فقط في
Environment على Render. لا ترفع ملف `.env` أبداً.

## أوامر البوت

- `/start` — بدء الاستخدام.
- `/help` — التعليمات.
- `/build وصف المشروع` — إنشاء مشروع.
- أو أرسل وصف المشروع مباشرة.
- للمخطط: أرسل صورة مع تعليق يشرح المطلوب.

## تشغيل محلي اختياري

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
# اضبط المتغيرات البيئية المذكورة أعلاه، ثم:
python bot.py
```

## الاختبارات

```bash
python -m pytest -q
```

## تنبيهات مهمة

- يجب أن يكون لدى المستخدم مفتاح OpenAI API صالح، وقد تُحتسب رسوم حسب استخدام API.
- لا توجد ضمانة أن المشروع المولد خالٍ من الأخطاء. نجاح الاختبارات لا يثبت صحة كل الوظائف.
- فحوصات Python الحالية ليست عزلاً أمنياً حقيقياً. لا تجعل البوت عاماً أو تشغّل كوداً غير موثوق
  في بيئة تحتوي أسراراً أو ملفات مهمة. لهذا الإصدار، الوصول مقيد افتراضياً: إذا لم تضبط
  `NOOR_ALLOWED_USER_IDS` فلن يسمح البوت لأي مستخدم.
- تشغيل اختبارات المشاريع المولدة يتم داخل عامل Render نفسه؛ للاستخدام العام واسع النطاق،
  انقل الاختبار إلى حاويات مؤقتة معزولة ومحدودة الصلاحيات والشبكة.
- Render قد يفرض رسوماً على Background Worker بحسب الخطة المتاحة. اختر الخطة المناسبة
  من لوحة Render وتحقق من الأسعار الحالية قبل النشر.
